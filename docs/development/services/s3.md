# S3 / LocalStack Development Notes

> Working with S3 in CloudCommerce — LocalStack for dev, S3-compatible API.

---

## S3 Client Configuration

Product service uses AWS SDK v3 with LocalStack:

```typescript
import { S3Client } from '@aws-sdk/client-s3'

const s3 = new S3Client({
  forcePathStyle: true,  // CRITICAL: LocalStack requires path-style URLs
  endpoint: process.env.S3_ENDPOINT ?? 'http://localhost:4566',
  region: 'us-east-1',
  credentials: {
    accessKeyId: process.env.AWS_ACCESS_KEY_ID ?? 'test',
    secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY ?? 'test'
  }
})
```

### Why `forcePathStyle: true`?

AWS SDK default uses **virtual-hosted style** URLs:
```
https://bucket.s3.us-east-1.localstack.cloud/key
```

LocalStack does not support virtual-hosted style URLs. The SDK produces:
```
http://localhost:4566/cloudcommerce-images/myimage.jpg
```

Without `forcePathStyle: true`, uploads fail with `AccessDenied` or `NoSuchBucket`.

## Bucket Pre-Creation

LocalStack does **not auto-create buckets**. The bucket must exist before first upload.

### Docker Compose
The LocalStack container runs an init script on startup that creates `cloudcommerce-images`.

### Verify bucket exists
```bash
aws --endpoint-url=http://localhost:4566 s3 ls s3://cloudcommerce-images/
```

### Create manually
```bash
curl -X PUT "http://localhost:4566/cloudcommerce-images"
```

### On Kind
```bash
kubectl exec -n infra localstack-0 -- curl -X PUT "http://localhost:4566/cloudcommerce-images"
```

## Uploading a File

```typescript
import { PutObjectCommand } from '@aws-sdk/client-s3'

const command = new PutObjectCommand({
  Bucket: 'cloudcommerce-images',
  Key: `products/${productId}/${filename}`,
  Body: fileBuffer,
  ContentType: mimetype
})

const response = await s3.send(command)
```

Resulting URL: `http://localhost:4566/cloudcommerce-images/products/64abc.../image.jpg`

## Listing Bucket Contents

```bash
aws --endpoint-url=http://localhost:4566 s3 ls s3://cloudcommerce-images/ --recursive
```

## Clear Bucket (Testing)

```bash
# List all objects
aws --endpoint-url=http://localhost:4566 s3api list-objects --bucket cloudcommerce-images --query 'Contents[].Key' --output text

# Delete all objects
aws --endpoint-url=http://localhost:4566 s3 rm s3://cloudcommerce-images/ --recursive
```

## LocalStack vs Real AWS

| Feature | LocalStack | Real AWS S3 |
|---------|-----------|-------------|
| `forcePathStyle` | Required | Optional (not needed) |
| Bucket auto-create | No — must create manually | Yes |
| Credentials | Any values (`test`/`test`) | Real IAM keys |
| Endpoint | `http://localhost:4566` | `https://s3.us-east-1.amazonaws.com` |

For production, remove `forcePathStyle: true` and use real AWS credentials.
